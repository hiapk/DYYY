# 喜欢页保护验收

当前验收版本为 DYYY 2.3-8，基于 2.3-0 #23；用户设备为 RootHide、iOS 16.5、抖音 39.8.0，IPA build 为 398016，原装插件来自 TrollStoreX 源的 2.3-0 #23。安装产物应为 `iphoneos-arm64e.deb`。2.3-1 曾出现闪现与密码框消失，2.3-2 用户录屏确认蒙层盖住设置、侧栏和底栏，2.3-3 用户反馈喜欢页完全不隐藏、摇动无密码框；以下修复验收仍需真机执行。

## 设置与密码

- 从抖音设置入口和双指长按入口分别设置密码。4、5、6 位数字可接受，保留前导零；3 位、7 位、字母、空白和全角数字不接受。
- 首次设置两次密码不一致、取消任意一步、连续点击确认，都不得留下半完成的密码记录。
- 首次设置成功自动开启保护，两套设置页都能显示最新状态。
- 输错旧密码不能修改密码或关闭保护。修改成功后旧密码失效，新密码可用。
- 导出配置不包含密码、盐值或校验值；导入任意配置、清除插件设置、清除抖音设置后，保护与密码仍保留。
- 密码记录读写失败时不能显示成功或自动解除保护。

## 页面与摇动

- 覆盖安装后完全退出抖音再打开，先确认设置里显示 2.3-8。
- 打开自己的主页，停在作品等其他标签时不应看到任何遮挡；切到喜欢立即显示空状态，资料卡与标签栏保持可见。
- 重放本次录屏：喜欢 → 侧栏 → 设置 → DYYY → 清理缓存 → 返回主页；所有面板、底部导航和作品页须完整显示。
- 对比开启前后头像、资料卡、底栏的位置和尺寸；不得通过改变宿主缩放来处理蒙层。

- 冷启动、直接落在喜欢页、从作品切到喜欢、左右滑动切换标签时，记录屏幕检查是否有一帧露出视频。
- 重放用户录屏动作：作品 → 日常 → 收藏 → 喜欢，分别点击和横向滑动，尤其检查“收藏仍选中、喜欢刚从边缘进入”的阶段。
- 从喜欢滑出一半后取消手势返回，继续保持隐藏；滑到作品/日常/收藏后，目标页正常显示。
- 使用深色和浅色主题检查空状态背景、图标、文字；顶部资料和喜欢标签不被遮挡，底部导航保留。
- 锁定后只遮挡自己的喜欢列表；顶部资料、标签、作品、日常、收藏及别人的主页应保持可用。
- 点击、长按、下拉刷新、滚动和 VoiceOver 均不能打开遮挡下的视频。
- 首屏为空列表、有占位图、列表翻页、横竖屏切换后，遮挡区域仍然正确。
- 解锁后滚动、切页再回来，单元格不得因复用残留隐藏；查看他人喜欢列表时不应用保护。
- 摇动一次只弹一个密码框；取消、输错、连续摇动、键盘关闭后再摇动，都保持正确状态。
- 摇动后等待数字键盘完全展开，再停留至少 5 秒输入密码，确认密码框持续显示且没有被布局刷新取消。
- 作品页、别人的喜欢页和其他页面摇动，不触发本功能。
- 开启全局透明度和一键清屏时，遮挡层仍不透明，且不会重复添加。

## 会话与系统切换

- 解锁后打开喜欢的视频再返回列表，不重复验证；切换标签、离开自己的主页后重新进入，应重新验证。
- 在列表与视频播放页分别切后台、锁屏、打开控制中心，检查多任务快照与回前台画面不露出受保护内容。
- 密码输入过程中退后台、切页或切号，旧输入框和后台验证结果不能解锁新会话。
- 点击密码确认的同时退后台，再回到喜欢页摇动：旧回调不得清除新输入框的状态，也不得出现重叠输入框。
- 切换账号后，即使复用了同一个主页控制器，也必须重新锁定。
- 当前页面缺少账号或选中标签依据时，应提示未适配；已遮挡的页面在临时布局变化时不能露出内容。

## 自动检查

`sh tests/run-like-privacy-tests.sh` 在 macOS 上编译并执行实际的密码、会话和标签判定代码。

`THEOS=/path/to/theos python3 tests/check-logos-header-hook.py` 覆盖 Hook 分组初始化及基线请求头 Hook 的 Logos 编译回归。

`python3 tests/check-like-privacy-scope.py` 验证只接入主页分页结构、不全局 Hook 窗口/滚动视图/控制器、不写宿主几何属性，并对照 IPA 接口快照核验全部 Hook 选择子。

构建需配置 Theos 和 iOS SDK，使用 `GITHUB_ACTIONS=true make package` 避免自动安装。设备安装前应先核对本地源码与已安装 DYYY 2.3.0 的差异，以及目标设备的包方案。
